What the assay measures

CLASP-seq brings two engineered cell populations together: one carries T-cell receptors, and the other displays peptide–MHC targets. Targeted sequencing recovers receptor and target identities. Controls and analysis determine which observations support an interaction.

We are sharing the protocol, materials and analysis resources so other labs can generate measurements for their own research and contribute to an open body of TCR–pMHC data. These measurements help test and improve the sequence and structure models.

The documented display system uses HLA class I constructs. The materials and construct manifests define the cell derivatives, sequences and HLA alleles for each library.

How the assay works

  1. 01

    Prepare the libraries

    Establish the receptor and target cell libraries. Check their identities, expression and representation, and keep aliquots of each input population.

  2. 02

    Pair and collect

    Combine violet-labelled receptor cells with GFP-positive target cells. Stabilize the preparation with the crosslinker BS3, then sort events carrying both labels.

  3. 03

    Capture and sequence

    Process the sorted preparation and the two inputs in separate 10x reactions. Recover targeted TCR and HLA–peptide products by PCR, then sequence them with Oxford Nanopore.

  4. 04

    Identify recovered partners

    Match reads to the library identities and assess evidence for receptor–target pairing. Evaluate controls, retain uncertain assignments and record the analysis settings.

Use the versioned laboratory protocol for reagent recipes, instrument settings, handling times and acceptance criteria. The overview here helps you plan the workflow.

Plan the assay day

Coordinate cell sorting, 10x capture and reverse transcription for the same day. The workflow proceeds from sorting into capture without an overnight pause. Agree on sample handoffs and instrument access before beginning.

Cell preparation and sorting

  • Culture facilities for the released cell derivatives.
  • Cell counting, expression and library-quality checks.
  • A sorter configured to recover the intended cell pairs.
  • Sample labels, controls and a collection plan.

Capture, sequencing and analysis

  • A Chromium setup compatible with the CLASP-seq protocol.
  • Targeted PCR, DNA quantification and fragment analysis.
  • Nanopore library preparation and sequencing.
  • Reference manifests, analysis software and data storage.

The source workflow uses a customized Chromium GEM-X Single Cell 3′ v4 procedure followed by targeted PCR and Nanopore sequencing. Use its CLASP-specific capture and read-processing instructions; an ordinary 10x V(D)J workflow has a different library structure.

Establish a small run first

Check pairing by flow cytometry with the appropriate fluorescence and reference controls. For a first implementation, we recommend taking a small run through stabilization, sorting, capture, sequencing and analysis before scaling. A flow-cytometry pilot alone does not measure recovery through the full workflow.

  • Before pairing: verify both libraries and their representation.
  • After sorting: check the recovered preparation and its composition, including larger aggregates.
  • Before sequencing: check target recovery, fragment identity and the contributions of each PCR product.
  • Before interpreting pairs: assess the controls and replicate evidence using the released criteria.

Keep the samples connected

The two input libraries and the sorted preparation enter separate 10x reactions. The experimental reaction then supplies two targeted PCR products: one for TCR identities and one for HLA–peptide identities. These products, together with the input products, are pooled for Nanopore library preparation.

These labels describe sample roles. Barcodes are interpreted within each reaction: the same barcode string in different reactions does not establish a pair. Input samples measure library representation; the pairing background requires its own controls and analysis.

From reads to pair evidence

The analysis needs to preserve the path from a sequencing read to its sample, partition and candidate library identity. It then evaluates the evidence for each receptor–target association using the controls, input representation and replicate information.

  1. Recover identities. Assign sample indexes and partition barcodes, then match reads to the versioned construct reference.
  2. Evaluate associations. Apply the documented rules for multiple or ambiguous identities and assess support for each candidate pair.
  3. Report the evidence. Save assignments, exclusions, control results and pair-evidence tables with the software and reference versions.
Interpret recovery with the controls

A co-positive sorting event or shared partition alone does not demonstrate specific recognition. A combination that was not recovered is not automatically a non-binder. Keep ambiguous assignments and insufficient evidence visible in the results.

Work through the released analysis example before processing a new run. Use the example to follow reads and reference files through to assignments and figures. CLASP-seq data need this assay-specific processing before they can be compared with model predictions.

Use DecoderTCR and DecoderTCR-Fold to study the resulting receptor–target candidates, while retaining experimental evidence separately from model scores. Shared datasets can support both training and evaluation; keep evaluation examples outside the corresponding training set.
