TCRvdb · AUROC

Recognition of receptors present in training

The evaluation scores the YLQ and GLC epitopes without supplying binding labels. Its receptors were present in training. This tests recognition of familiar receptors; it does not establish performance on new receptors.

AUROC measures how well the model ranks labeled binders above labeled non-binders across possible score thresholds.

300M: 0.853 · 600M: 0.819 · 6B: 0.779

Evaluation limits

The TCRs were seen in training (VDJdb). This is a recognition check, not a generalization test.

IMMREP23 · Macro AUROC

Receptors with little training overlap

The IMMREP23 challenge evaluates receptors with little training overlap. Performance is summarized across epitopes, giving each epitope equal weight.

Macro AUROC is the average AUROC across epitopes. Individual epitope results can differ from this average.

300M: 0.659 · 600M: 0.698 · 6B: 0.687

Evaluation limits

The source reports ~0.3% training overlap. Reported scores summarize performance across epitopes.

Viral / ePytope-TCR · Macro AUROC

Comparison on viral epitopes

The ePytope-TCR benchmark compares published tools on viral-epitope specificity. The comparison includes a specified policy for tools that return no prediction.

Macro AUROC summarizes discrimination across the evaluated viral epitopes. Interpret the results alongside the policy for missing predictions below.

300M: 0.640 · 600M: 0.657 · 6B: 0.644

Evaluation limits

Missing predictions are scored at 0.5 in this comparison.

PRP · Macro AUPRC

Retrieval from a large peptide library

PRP asks the model to rank an anchor-fixed peptide library for HLA-B*27:05 receptors. True binders are rare. The evaluation asks how many of them appear among the highest-ranked candidates.

Macro AUPRC summarizes precision–recall performance across receptor clones. The authors also report recall@K: the fraction of true binders recovered among the top K candidates. Precision measures the fraction of selected candidates that are binders; recall measures the fraction of all binders recovered.

300M: 0.303 · 600M: 0.351 · 6B: 0.391

Evaluation limits

A retrieval task with ~0.4% prevalence. This metric must not be read as accuracy or compared numerically with AUROC.

Score the public IMMREP23 test set

The repository includes the IMMREP23 challenge test CSV and a command for scoring it. Running that command produces per-pair scores. It does not, by itself, recreate every published comparison or plotting workflow.

Shell · after installation and checkpoint download
uv run python -m DecoderTCR.utils.predict_from_genes \
  -i results/immrep23/immrep23_test.csv \
  -o immrep23_scored.csv \
  -m DecoderTCR-ESMC_600M -d cuda:0

Adapted from the pinned repository command, with an explicit device. Use the setup guide before running it; the weights and germline data must be installed. If you followed the CPU setup, replace the last line with -m DecoderTCR-ESMC_300M -d cpu to use the checkpoint you installed. Keep the model and device settings with your results.
