Beginner setup

Use TCR-Workbench with a coding agent

Set up DecoderTCR on your computer and run your first analysis. A coding agent can run commands, check your files and explain the results as you go.

Use a Mac or Linux computer with an internet connection and room for the model files. On Windows, run Workbench in WSL (a Linux environment). For a first run without local setup, use the browser tutorial.

1. Get Workbench

  1. Open the TCR-Workbench repository.
  2. Select Code → Download ZIP, then extract the download.
  3. Put the extracted folder where you want to keep it, and leave it there after setup. It contains tcr.py, AGENTS.md and a skills folder.
Already use Git?
Terminal
git clone https://github.com/akdslab/tcr-workbench.git
cd tcr-workbench
How do I open a terminal in the Workbench folder?

On a Mac, open Terminal; on Linux, open your Terminal application. Type cd (including the space), drag the Workbench folder into the window, and press Enter. On Windows, open your WSL terminal and use cd with the folder’s Linux path. Run ls to check that you can see tcr.py.

Paste blocks labelled Terminal there. Paste blocks labelled Message to your coding agent into the agent’s conversation.

2. Open a coding agent

Choose one of the tools below. A desktop app is a good starting point if you are new to coding agents. Open the Workbench folder from step 1 so the agent can read its instructions and run the tools.

Anthropic · Claude Code
  1. Install the Claude desktop app using the official setup guide and sign in with an account that has Claude Code access.
  2. Open the Code tab and select Local (or WSL on Windows).
  3. Select the extracted Workbench folder and start a conversation.

Already use the terminal? Install Claude Code CLI, open a terminal in the Workbench folder and run claude.

OpenAI · Codex
  1. Install the ChatGPT desktop app using the official setup guide and sign in with an account that has Codex access.
  2. Choose Codex and open the Workbench folder as a local project.
  3. Start a new conversation that works with that folder on your computer.

Already use the terminal? Install Codex CLI, open a terminal in the Workbench folder and run codex. On Windows, use the WSL terminal for these Workbench commands.

Google · Antigravity (agy)
  1. Install Antigravity CLI with the command below in a Mac, Linux or WSL terminal:
Terminal · install Antigravity
curl -fsSL https://antigravity.google/cli/install.sh | bash
  1. Reopen your terminal, return to the Workbench folder, and launch:
Terminal · from the Workbench folder
agy
  1. Complete sign-in and the first-launch prompts, confirm the Workbench folder, then paste the setup message in step 3 below.

See the official installation guide. If you prefer the desktop app, the same guide explains how to add the Workbench folder to a project and use Local mode.

3. Install the model

Workbench includes two skills: instruction files that tell the agent how to install the software and run analyses. They are already in the folder you downloaded. Paste this message into your agent’s conversation:

Message to your coding agent · setup
Read AGENTS.md, skills/tcr-workbench-setup/SKILL.md, and
skills/tcr-workbench/SKILL.md in this folder.
Confirm this is the Workbench folder containing tcr.py.
Check for Git, Python 3.9 or newer, and Python's venv support.
If any are missing, help me install them first. Then run
python3 tcr.py doctor.
Install DecoderTCR 1.5.0 with the default 300M model, choosing the
appropriate device for my computer. Use these setup options:
--decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8"
--weight-source huggingface
Run python3 tcr.py doctor --deep and confirm the model package, weight
source, framework and germlines are ready. If anything fails, explain and resolve it before continuing.

This installs DecoderTCR 1.5.0 from GitHub and uses public Hugging Face weights. No Hugging Face account is needed. Start with 300M; 600M and 6B are also available.

Install with terminal commands instead

Install Git and Python 3.9 or newer with virtual-environment support. Open a terminal in the Workbench folder and run one command for your computer:

Mac with an Apple M-series chip
Terminal
python3 tcr.py setup --device apple \
  --decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8" \
  --weight-source huggingface
CPU on Mac or Linux
Terminal
python3 tcr.py setup --device cpu \
  --decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8" \
  --weight-source huggingface
NVIDIA GPU on Linux (working NVIDIA drivers required)
Terminal
python3 tcr.py setup --device gpu \
  --decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8" \
  --weight-source huggingface

Then check the installation:

Terminal
python3 tcr.py doctor --deep

Confirm that DecoderTCR, the model registry and germlines are ready before continuing.

4. Run an example

This example predicts amino-acid preferences for a nine-residue peptide presented by HLA-A*02:01. You do not need to prepare an input file. Send:

Message to your coding agent · first analysis
Use the Workbench analysis skill to run this example:
python3 tcr.py pmhc-profile --hla 'HLA-A*02:01' --length 9 --out results/first-profile
If that output folder already exists, use a new folder instead.
Open the resulting report.html and explain the main plots.
Run the example in a terminal
Terminal
python3 tcr.py pmhc-profile --hla 'HLA-A*02:01' --length 9 --out results/first-profile

Run this from the Workbench folder. Use a new output folder when you repeat an analysis.

The first run may need to download the weights (about 1.3 GB for 300M). Later runs reuse them.

5. Open your results

Open results/first-profile/report.html in your browser, or the report in the new output folder your agent used. It shows an amino-acid heatmap and sequence logo. The same folder contains profile.csv and pssm.csv for further analysis.

These plots show the model’s predicted peptide preferences. They do not measure binding or give a probability of recognition.

Use your own data

Choose a task below. Each scoring tutorial includes example inputs and a message you can give your agent.

  • Score peptides for a TCR–HLA combination — start with paired receptor annotations, HLA and a peptide or peptide panel.
  • Score peptides with HLA alone — start with peptide sequences and an HLA allele.
  • Screen a paired TCR repertoire — start with processed repertoire data and a peptide panel.
  • Explore peptide preferences or match receptors to reference data — see the Workbench workflow guide.

For any task, tell the agent your research question and where your files are. For example, replace the bracketed text and send:

Message to your coding agent · your data
Read AGENTS.md and skills/tcr-workbench/SKILL.md.
My question is: [describe what you want to compare or investigate].
My input files are: [file paths].
Check which workflow fits and whether the required fields are present.
Start with a small example, keep my original files unchanged, and save
all outputs in a new results folder. Explain the results and any rows
that could not be processed. Record the model and settings used.

If a step fails

Give your agent the exact error and ask it to follow skills/tcr-workbench-setup/SKILL.md. If you rerun setup, keep the --decoder-source and --weight-source options from step 3. The setup skill covers missing dependencies, downloads, network certificates and memory limits. Include the failed command and error when asking for help.
