Setup guide

Set up the TCR-Workbench CLI

Install DecoderTCR 1.5 on your computer, run an example, and open the results. Follow the commands below or let a coding assistant use the bundled skills.

You need Git, Python 3.9 or newer, an internet connection and space for the model files. Use Mac, Linux or Windows with WSL.

1. Get the code

Open a terminal in the folder where you want to keep Workbench, then run:

Terminal · Mac, Linux or WSL
git clone https://github.com/akdslab/tcr-workbench.git
cd tcr-workbench
python3 --version
git --version

The launcher needs Python 3.9 or newer with virtual-environment support; setup manages uv and Python 3.12 for the model environment. If Python or Git is missing, install Python or Git before continuing. Keep this folder in the same location after setup.

Prefer to download a ZIP instead of using Git?

On github.com/akdslab/tcr-workbench, choose Code → Download ZIP, extract it, and enter the extracted folder in your terminal. Git is still needed for the model installation in step 3.

What is a terminal, and where do I paste commands?

A terminal is a window where you type commands and press Enter to run them. On a Mac, open Terminal from Spotlight. On Linux, open your Terminal application. Native Windows setup is untested; use a Linux environment through WSL and run these commands in its terminal.

To move into a folder, type cd followed by its full path in quotation marks, then press Enter. You can often drag the folder into the terminal to insert its path. cd means “change directory”. Run pwd in your Mac, Linux or WSL terminal to check the current folder.

Paste blocks labelled Terminal into that window. Paste blocks labelled Message to your assistant into the assistant’s conversation.

2. Set up a coding agent (optional)

This step is optional but helpful. A coding assistant can run the install for you and explain each step, which is useful if you don't spend much time in a terminal. If you'd rather type a few commands yourself, skip this step and go to install by hand in step 3.

If you do want one, choose the tool you have access to — you only need one. Codex and Claude Code have desktop and terminal options; Gemini CLI runs in a terminal. When asked which folder to open, choose the tcr-workbench folder from step 1.

Anthropic · Claude Code
  1. Install the desktop app using the official setup guide.
  2. Sign in with an account that has Claude Code access.
  3. Open the Code tab, select Local, then choose the tcr-workbench folder. Follow any operating-system setup steps in the guide.

For a terminal interface, follow the Claude Code CLI installation guide, open a terminal in tcr-workbench and run claude.

OpenAI · Codex
  1. Follow the official desktop app guide to install the app for your computer.
  2. Sign in using an account with Codex access. See the authentication guide for account and API-key options.
  3. Open tcr-workbench as a local project and start a Codex session in Local mode.

For a terminal interface, follow the Codex CLI installation guide, open a terminal in tcr-workbench and run codex.

Google · Gemini CLI
  1. Install the current LTS version of Node.js, which includes the npm installer. Reopen your terminal.
  2. Open a terminal in tcr-workbench and run the commands below one line at a time.
Terminal · Mac, Linux or WSL
node --version
npm --version
npm install -g @google/gemini-cli
gemini
  1. Follow the sign-in prompt. Use the official authentication guide for personal, university or company account requirements.

The installation guide lists supported systems and prerequisites.

Message to your assistant · folder check
Show the full path of this folder and list its files.
I expect to see tcr.py and a skills folder. Do not install anything yet.

Check: the path should be your tcr-workbench folder and the listing should include tcr.py. If the assistant only describes how to list files, check that you opened a local coding session in this folder.

3. Install TCR-Workbench

Send the setup message to your coding agent, or use the command for your computer. Both install DecoderTCR 1.5.0 from GitHub and download model weights from Hugging Face. No Hugging Face account is needed.

Let your coding agent install Workbench

Open the tcr-workbench folder in your coding assistant and send:

Message to your assistant · install
Read AGENTS.md, skills/tcr-workbench-setup/SKILL.md, and
skills/tcr-workbench/SKILL.md in this folder.
Check my machine and existing installation with python3 tcr.py doctor.
Install the default 300M model using the appropriate device for my computer.
Use these setup options:
--decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8"
--weight-source huggingface
Run python3 tcr.py doctor again and report whether DecoderTCR,
the registry and germlines are ready. Explain any error before continuing.
Do not analyze my data yet.

The setup skill guides installation into a managed environment. Apple setup may also download and prepare weights. When setup succeeds, the assistant should report your device, the model (DecoderTCR 300M by default) and a reachable weight source.

Setup instructions: skills/tcr-workbench-setup/SKILL.md

Or install by hand

From the tcr-workbench folder, run one of these commands. Start with the default 300M model.

Mac with an Apple M-series chip
Terminal
python3 tcr.py setup --device apple \
  --decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8" \
  --weight-source huggingface
CPU on Mac or Linux
Terminal
python3 tcr.py setup --device cpu \
  --decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8" \
  --weight-source huggingface
NVIDIA GPU on Linux

Requires working NVIDIA drivers.

Terminal
python3 tcr.py setup --device gpu \
  --decoder-source "git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8" \
  --weight-source huggingface

Then confirm the install:

Terminal
python3 tcr.py doctor

Setup installs the dependencies and saves your device choice. Apple setup also downloads and prepares weights; CPU and NVIDIA runs download them when first needed. The commands use a fixed DecoderTCR 1.5.0 source revision.

Check: however you installed, run python3 tcr.py doctor (or ask the assistant to) and confirm DecoderTCR, the model registry and germlines are ready. A “core-only installation” message means model setup is not finished.

4. Run your first analysis

Once doctor succeeds, run a profile for a nine-residue peptide in the context of HLA-A*02:01. Ask the assistant, or paste the command yourself from the tcr-workbench folder:

Terminal
python3 tcr.py pmhc-profile --hla 'HLA-A*02:01' --length 9 --out results/first-profile

If weights are not already cached, the first analysis fetches them from the configured registry (about 1.3 GB for the 300M model). Apple setup may already have downloaded and converted them. Later runs reuse the cache. Keep the computer awake during downloads and model preparation. Use a new --out folder for each run, such as results/first-profile-2 when repeating this example.

Behind a CZ Biohub (or other TLS-inspecting) network?

On a network that inspects secure traffic, the first weight download can fail even when the network is otherwise fine. The common fix is to disable Hugging Face's accelerated transfer before scoring:

Terminal
export HF_HUB_DISABLE_XET=1
python3 tcr.py pmhc-profile --hla 'HLA-A*02:01' --length 9 --out results/first-profile

If you still see a certificate error, ask your assistant to follow the “corporate / TLS-inspecting proxy” section of the bundled setup skill, which adds the system certificate bundle.

5. Check the result

Open results/first-profile/report.html in your browser for the amino-acid heatmap, sequence logo and run details. Alongside it:

  • profile.csv — the amino-acid probabilities at each peptide position.
  • pssm.csv — the position-specific scoring matrix.
  • Run details — the checkpoint, device and settings that produced the result.

The motif describes positional preferences the model predicts for this MHC; it is a hypothesis, not a measured binding motif or a probability of binding. Continue to the sequence-model tutorial to score a TCR–pMHC pair and read a PLL score, then try a small table of your own inputs.

If a step fails

“The launcher needs Python 3.9 or newer”

Your system Python is too old. Install Python 3.9+ and reopen the terminal; setup then provisions its own Python 3.12 for the model.

“Apple setup requires macOS on Apple Silicon”

You used --device apple on a computer that is not an Apple M-series Mac. Use --device cpu instead.

“Automatic NVIDIA GPU setup targets Linux”

You used --device gpu outside Linux. Use --device apple on an Apple Silicon Mac or --device cpu on a supported Mac/Linux setup. For Windows, use WSL/Linux.

The weights will not download

Check your connection, available disk space and the configured model repository. The current Hugging Face registry allows downloads without an account. If you see an access error, confirm that you are using this repository. Follow the setup skill for TLS or transfer troubleshooting.

A download fails or the model runs out of memory

If setup or scoring stops with an estimated-memory message, the model is too large for this computer. Use the default 300M model on CPU, or move to a machine with more memory or a GPU. Do not override the memory guard unless you understand the risk.

“DecoderTCR not installed” or “Setup is needed” at analysis time

Rerun the setup command for your computer, including --decoder-source and --weight-source huggingface, then run python3 tcr.py doctor. If setup fails, include the command and error when asking for help.

The terminal says a command was not found

Reopen the terminal after installing, and make sure you are in the tcr-workbench folder (run python3 tcr.py doctor there). For Gemini CLI permission errors, follow npm’s installation guide.

A row or peptide has no score

Read the reconstruction reason columns and check the V/J gene names, CDR3 sequences and HLA allele. A missing score is not evidence that a pair does not bind.
