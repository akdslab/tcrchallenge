Does a peptide fit an HLA context?

This workflow scores a peptide with an HLA molecule, without conditioning on a TCR. It addresses the peptide–HLA side of recognition. To ask about a particular receptor, use the TCR–pMHC scoring tutorial.

A sequence score, not an affinity measurement

The output is PLL. It can help rank candidates under a consistent scoring setup; it does not report measured binding, a dissociation constant or a probability of T-cell recognition.

Supply a peptide and an HLA allele

The example looks up the HLA component sequences from the bundled reference, then passes them to the scoring function. For the class I HLA example below, these are the HLA heavy chain and beta-2 microglobulin. If the allele is absent, inspect the error and use dt.list_alleles(); do not substitute a different allele silently.

Run HLA-only scoring

Python · adapted from the public API
import DecoderTCR as dt
from DecoderTCR.reconstruct.hla import lookup_hla
import pandas as pd

model = "DecoderTCR-ESMC_300M"
allele = "HLA-B*27:05"
hla_a, hla_b = lookup_hla(allele)
# Public README peptide; no experimental label is implied.
pairs = pd.DataFrame([{
    "name": "public_example", "allele": allele,
    "HLA_a": hla_a, "HLA_b": hla_b, "Peptide": "LRVMMLAPF",
}])
scored = dt.score(pairs, model=model, device="cpu", with_tcr=False)
scored.to_csv("hla_only_scores.csv", index=False)
print(scored[["name", "allele", "Peptide", f"pll_{model}"]])

Source: with_tcr=False selects pMHC-only scoring. HLA lookup.

Read the output

Open hla_only_scores.csv. Compare the same checkpoint, HLA context and peptide length before using the ranking to select experiments. This full-sequence API does not provide the reconstruction flags used by the gene-based tutorial.
