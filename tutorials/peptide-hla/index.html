Score a peptide with HLA

Evaluate the peptide–HLA component of binding with the TCR-Workbench CLI, without supplying a T-cell receptor.

Before you run

pmhc-score evaluates a panel of peptides in an MHC context without a TCR input. Install the tool first — see Set up the TCR-Workbench CLI — and run the command from the folder that holds tcr.py. Setup saves your device choice, so no --device flag is needed.

Does a peptide fit an HLA context?

This workflow scores a peptide with an HLA molecule, without conditioning on a TCR. It addresses the peptide–HLA side of recognition. To ask about a particular receptor, use the TCR–pMHC scoring tutorial.

A sequence score, not an affinity measurement

The output is PLL. It can help rank candidates under a consistent scoring setup; it does not report measured binding, a dissociation constant or a probability of T-cell recognition.

Supply a peptide panel

Create a CSV with a peptide column and an hla column. One row is enough; add more to compare candidates.

panel.csv
peptide,hla
GILGFVFTL,HLA-A*02:01
NLVPMVATV,HLA-A*02:01

The tool looks up the HLA component sequences from its bundled reference before scoring. If an allele is absent, the row is kept and marked in the output rather than silently substituted.

Run HLA-only scoring

Score the example panel that ships with the repository, or point --panel at your own CSV:

Terminal
python3 tcr.py pmhc-score --panel examples/panel.csv --out results/pmhc-panel

The first run downloads the model weights once into the tool's cache. Use a new --out folder for each run.

The report compares the panel against 1,000 random peptides per MHC/length group as a reference distribution. These are not known nonbinders; add --background-peptides 0 to omit the comparison.

Read the output

Open results/pmhc-panel/report.html. It shows the top-ranked peptides within each MHC and peptide-length group, with their score distribution against the random peptides. Every input stays in the full CSV tables beside the report, including rows that could not be scored. Compare the same checkpoint, HLA context and peptide length before using a ranking to choose experiments.

If you have only the MHC and a peptide length and want positional preferences instead of a candidate ranking, use pmhc-profile, which writes an amino-acid profile and PSSM for a chosen length.
