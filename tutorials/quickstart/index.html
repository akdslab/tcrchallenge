Score a TCR–pMHC pair

Before you run

Install TCR-Workbench with the coding-agent setup guide. This tutorial uses its default 300M model and saves an HTML report you can open in your browser.

Run every command from the folder that holds tcr.py. Setup saves your device choice, so the commands below do not need a --device flag.

Eight fields describe one pair

Supply the V and J gene names and CDR3 amino-acid sequence for each receptor chain, an HLA allele, and the peptide to score. Include each CDR3's conserved starting C and terminal F/W anchors. Look up an unfamiliar term.

The public example. It does not establish whether the pair binds.
FieldCLI flagExample
Alpha-chain V gene--travTRAV21
Alpha-chain J gene--trajTRAJ6
Alpha-chain CDR3--cdr3aCAVRPGGAGPFFVVF
Beta-chain V gene--trbvTRBV7-9
Beta-chain J gene--trbjTRBJ2-7
Beta-chain CDR3--cdr3bCASSLGQAYEQYF
HLA allele--hlaHLA-B*27:05
Peptide to score--peptideLRVMMLAPF

The tool reconstructs the full receptor chains from your gene names and looks up the HLA sequence before scoring. An allele name is a lookup key, not an amino-acid sequence; check the report's reconstruction details and any warnings.

Score the example

From the folder containing tcr.py, score the public receptor against a single peptide:

Terminal
python3 tcr.py tcr-score \
  --trav TRAV21 --traj TRAJ6 --cdr3a CAVRPGGAGPFFVVF \
  --trbv TRBV7-9 --trbj TRBJ2-7 --cdr3b CASSLGQAYEQYF \
  --hla 'HLA-B*27:05' --peptide LRVMMLAPF --out results/first-pair

Model weights download from Hugging Face automatically if needed. See the local setup requirements. Use a new --out folder for each run.

Score a panel of peptides

To compare several peptides for one receptor and HLA, replace --peptide with --panel and a CSV with a peptide column. An optional hla column must match --hla. The bundled panel uses HLA-A*02:01, so this example changes --hla to match:

Terminal
python3 tcr.py tcr-score \
  --trav TRAV21 --traj TRAJ6 --cdr3a CAVRPGGAGPFFVVF \
  --trbv TRBV7-9 --trbj TRBJ2-7 --cdr3b CASSLGQAYEQYF \
  --hla 'HLA-A*02:01' --panel examples/panel.csv --out results/tcr-panel

By default the panel is also compared against 1,000 random peptides per MHC/length group as a reference distribution. These are not known nonbinders; add --background-peptides 0 to omit the comparison.

Read the result

Open results/first-pair/report.html for the single-pair run, or results/tcr-panel/report.html for the panel. The CSV files are in the same folder. Check:

Could the input be scored?

Start with the status and reason columns. An Unresolved row could not be scored and needs review; it does not mean the pair fails to bind. Failed rows remain in the table.

Which model produced the score?

The run details record the checkpoint, device, species and settings. Compare scores only within the same checkpoint, context and peptide length.

What does the score mean?

The PLL is the mean log-probability the model assigns to the peptide after the whole peptide is masked, in the supplied receptor and HLA context. A higher score ranks a candidate higher. It is not a probability of binding.

Try your own receptor

Replace the six gene and junction values with your own annotations, keeping each CDR3's conserved C and F/W anchors, and set --hla to your allele. Use a new --out folder each time. To score many receptors at once from a single-cell experiment, use the repertoire screening tutorial. For a peptide in an MHC context without a TCR, use peptide–HLA scoring.
