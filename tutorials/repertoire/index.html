Start from receptor annotations and a target list

Use filtered_contig_annotations.csv from a single 10x Cell Ranger V(D)J sample. The contig table has one row per assembled chain, so it must be converted into paired receptors. A gene-expression count matrix contains different measurements and cannot be used as this input.

Create peptide_targets.csv with columns peptide and hla. Supply the known HLA context or explicitly identify a hypothetical context being tested. A repertoire file alone does not establish HLA typing or peptide specificity.

10x annotation schema used by this tutorial (Cell Ranger 8.0). Check your export’s columns if using another version.

Check the chain pairing

The teaching helper groups records by cell barcode within one sample. It retains high-confidence, productive, full-length chains from called cells and requires exactly one distinct alpha and one distinct beta chain. Identical gene/CDR3 records are counted once. Cells with missing or multiple eligible chains are recorded in an audit file rather than assigned an arbitrary pair.

This is a conservative tutorial policy. Biologically valid dual-chain cells may need a different, explicitly chosen analysis. Keep sample identifiers when combining experiments; barcode strings can repeat between samples.

Python · adapted from the public API
import pandas as pd
from tutorial_helpers import prepare_10x

# One sample per call. Supply the HLA context in the target table.
contigs = pd.read_csv("filtered_contig_annotations.csv", keep_default_na=False)
targets = pd.read_csv("peptide_targets.csv", keep_default_na=False)
queries, audit = prepare_10x(
    contigs.to_dict("records"), targets.to_dict("records"), sample_id="sample_01"
)
pd.DataFrame(audit).to_csv("pairing_audit.csv", index=False)
if not queries:
    raise ValueError("No unambiguous paired receptors. Inspect pairing_audit.csv.")
query_table = pd.DataFrame(queries)
query_table.to_csv("repertoire_queries.csv", index=False)
print(f"{len(query_table)} receptor-target comparisons prepared.")

Score receptor–target combinations

The prepared table contains one row per accepted receptor and supplied peptide–HLA target. Inspect the pairing audit and total comparison count first. The default first run scores only a few rows; disable first_run after checking the output to process the selected table. Start with a small target list when preparing a large repertoire: the number of comparisons grows with both receptors and targets.

Python · adapted from the public API
import DecoderTCR as dt

# First inspect a small batch. To score the full table, set first_run=False.
first_run = True
selected = query_table.head(3) if first_run else query_table
scores = dt.score_from_components(
    selected, model="DecoderTCR-ESMC_300M", device="cpu"
)
metadata = selected[["name", "sample_id", "barcode", "target_index"]]
result = metadata.merge(scores, on="name", validate="one_to_one")
result.to_csv("repertoire_scores.csv", index=False)
print(result[["name", "ok", "tcr_reason", "hla_reason",
              "pll_DecoderTCR-ESMC_300M"]])

Keep cell identity and uncertainty

The output retains sample, barcode and target identifiers alongside reconstruction flags and PLL. Preserve failed rows. Examine rankings within a fixed target and scoring setup; do not treat scores across different HLA contexts or peptide lengths as calibrated against one another. A high score is a prediction for follow-up, not an experimentally established specificity label for that cell.

Compare predictions with single-cell measurements

This worked example starts with processed data from a public 10x CD8 T-cell experiment. It combines paired T-cell receptor sequences, experimental peptide–MHC binding labels, and gene-expression measurements in an .h5ad file. The pairing and labeling have already been done; this file does not go through the raw-contig helper above.

The question is whether receptor scores distinguish the cells assigned different experimental binding labels. Score each distinct paired receptor against GILGFVFTL and ELAGIGILTV, both with HLA-A*02:01, then connect the results back to individual cells.

Prepare the receptor–target table

The example’s input-preparation helper reads donors_benchmark.h5ad and writes decoder_input.csv plus cell_tcr_map.csv. The first table contains the receptor genes, CDR3 sequences, HLA and peptide. The second preserves the link between cells and receptors. Experimental labels accompany the analysis but are not model inputs.

Score distinct receptor inputs

Group identical paired receptor inputs and score each receptor–target combination once under the same model settings. Keep the cell mapping and all reconstruction failures. Begin with a small batch before scoring the full example.

Compare scores with the assay labels

Begin at the receptor level. The supplied labels combine ITRAP, ICON and 10x dextramer calls; dextramer measurements provide the experimental binding readout. Follow the preparation record for positive, negative and unresolved labels. A missing label or failed reconstruction is not a negative observation.

Map predictions back to cells

Join scores through the receptor-to-cell mapping. Compare the experimental labels and sequence scores on the gene-expression map, or UMAP. This view connects predictions with cell context; repeated cells carrying the same receptor are not independent predictions.

Read the comparison at the right level

The example includes a selected set of assay-labeled cells and sampled negative clones. Report how that set was made and how many inputs could be scored. Precision–recall results depend on the positive fraction in the selected set. Cell-level summaries give more weight to expanded clones, so show receptor-level comparisons first. Check overlap with model training data before interpreting results as performance on unseen receptors.

Use experimental labels as the reference for this comparison, with their documented controls and filtering. They do not establish every target a receptor can recognize or whether binding activates the T cell.
