Screen a 10x T-cell repertoire

Score paired receptors from a single-cell experiment against peptide–HLA targets with the TCR-Workbench CLI.

Before you run

repertoire-score compares clonotypes from a single-cell experiment against a candidate peptide panel. Install the tool first — see Set up the TCR-Workbench CLI — and run every command from the folder that holds tcr.py. Start from processed receptor tables, not raw FASTQ files.

Input files

  • Repertoire: a 10x Cell Ranger filtered_contig_annotations.csv (--format 10x), an AIRR rearrangement file (--format airr), or a paired receptor table (--format paired).
  • Panel: a CSV with peptide,hla columns — the peptide–MHC targets to screen against.
  • Donors (recommended): a CSV with donor_id,hla, one MHC restriction per row, so scoring uses each donor's typing.

Without donor typing the panel still sets the MHC context, but donor compatibility is unconfirmed. Current model scoring needs a complete, unambiguous alpha–beta pair; dual-alpha chains, nonproductive rearrangements and incomplete pairs are kept in the audit rather than scored.

Score a repertoire

Try the bundled example, which contains three synthetic cells:

Terminal
python3 tcr.py repertoire-score \
  --input examples/paired.csv --format paired \
  --panel examples/panel.csv --donors examples/donors.csv --out results/repertoire-demo

For a single-donor 10x export, put your files in data/ and name the donor:

Terminal
python3 tcr.py repertoire-score \
  --input data/filtered_contig_annotations.csv --format 10x --donor-id donor_1 \
  --panel data/peptides.csv --donors data/donors.csv --out results/donor_1-screen

Use the same donor_1 identifier in the donor table. The number of comparisons grows with both receptors and targets, so start with a small panel for a large repertoire. The first run downloads the model weights once; use a new --out folder for each run.

10x annotation schema (Cell Ranger 8.0). A gene-expression count matrix is a different measurement and cannot be used as this input.

Read the results

Open results/repertoire-demo/report.html. The output tables link cells, chains and receptors, with reconstruction reasons and PLL. Scores are ranked within each receptor, MHC and peptide-length group. Keep the whole output folder together so the table links work.

  • Audit: incomplete, dual-alpha and ambiguous receptors stay in the records; alternative receptors are not independent cells.
  • Ranking: compare scores only within a fixed target and scoring setup, not across HLA contexts or peptide lengths.
  • Interpretation: a high score is a prediction for follow-up, not an established specificity label for that cell.

Compare with experimental measurements

If your cells carry experimental binding labels — for example dextramer calls from a processed single-cell dataset — you can compare them with the scores as a downstream step. Begin at the receptor level, since cell-level summaries give more weight to expanded clones, and report how the compared set was built and how many inputs could be scored. Check overlap with model training data before reading results as performance on unseen receptors. Experimental labels, with their documented controls, are the reference; a missing label or failed reconstruction is not a negative observation.
