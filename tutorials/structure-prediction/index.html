Describe the complex

A TCR–pMHC complex contains the receptor and its peptide–MHC target. This tutorial uses single-sequence prediction: supply an amino-acid sequence for each protein component, without preparing a multiple sequence alignment. “Single sequence” describes the input method; the complex still contains several chains.

  • T-cell receptor: the paired alpha and beta chain sequences.
  • Peptide: the sequence of the presented fragment.
  • HLA: the allele and the component sequences required by the notebook.

Follow the notebook’s sequence-length and chain-label instructions. If you start from V/J genes and CDR3 annotations, check its reconstruction procedure before submitting the complex. Gene names and short CDR3 sequences do not by themselves specify every residue in a structure.

Predict your first structure

  1. Run the supplied example. Keep the notebook’s example inputs and model settings for your first run.
  2. Inspect the input summary. Match each chain label to its sequence and biological role. Resolve missing or rejected inputs before prediction.
  3. Run structure prediction. Follow the notebook’s prediction cells and retain any messages alongside the result.
  4. Use your own complex. Replace the example sequences, check the summary again and save the new run separately.

Read the structure

Locate the receptor, peptide and HLA in the predicted complex. Examine how the receptor is positioned relative to the presented peptide, and read any confidence output using the model documentation. Confidence can differ across the complex; an uncertain interface deserves particular care.

A structure is a testable hypothesis

A predicted arrangement can suggest contacts or mutations to investigate. It does not by itself establish binding affinity, antigen specificity or T-cell activation.

To obtain a model score for candidate receptor–target pairs, follow the separate DecoderTCR-Fold pair-scoring tutorial.

Keep the run with the result

Save the predicted structure, the notebook and its outputs, the original input sequences with chain labels, and any confidence files. Record the model version, notebook revision, hardware and prediction settings. Download the result files before ending the Colab session; its runtime storage is temporary.
