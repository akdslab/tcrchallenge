Design within a receptor template

Start with a peptide–HLA target and a template TCR. In the public API, IEGR can redesign an alpha CDR3, a beta CDR3, or both CDR3 regions. Their lengths come from the template; this does not generate a complete receptor with an unconstrained architecture.

This example changes the beta-chain CDR3 while keeping the alpha chain, gene choices, peptide and HLA fixed. Supply all eight component fields. The public example is used to demonstrate the API, without claiming that it is a validated binder.

Generate CDR3 candidates

Python · adapted from the public API
import DecoderTCR as dt
import pandas as pd

clone = {
    "trav": "TRAV21", "traj": "TRAJ6", "cdr3a": "CAVRPGGAGPFFVVF",
    "trbv": "TRBV7-9", "trbj": "TRBJ2-7", "cdr3b": "CASSLGQAYEQYF",
    "hla": "HLA-B*27:05",
}
clone["peptide"] = "LRVMMLAPF"  # Public example target; not a validated label.
# The beta-chain CDR3 changes; alpha, V/J genes, HLA and peptide stay fixed.
designs = dt.iegr(
    clone, region="cdr3b", n=3, temperature=0.1,
    seed=42, gibbs_rounds=2, gibbs_subset_size=5,
    from_genes=True, model="DecoderTCR-ESMC_300M", device="cpu",
)
designs.to_csv("cdr3b_designs.csv", index=False)
print(designs)

Source: supported CDR3 regions and template lengths.

sequence contains the redesigned region, not a full alpha or beta chain. phase and step identify where the candidate arose during refinement. Do not supply length for a CDR3 region. IEGR retains the earliest unique designs up to n, rather than selecting the best or final states. This first example uses a small refinement run.

Reconstruct and score the variants

Insert each candidate into the matching component field and reconstruct the receptor before interpreting it. Some generated regions may fail reconstruction; keep those rows and read their reason columns.

Python · adapted from the public API
variants = []
for i, row in designs.iterrows():
    variant = dict(clone)
    variant["name"] = f"cdr3b_candidate_{i}"
    variant["cdr3b"] = row["sequence"]
    variants.append(variant)
if not variants:
    raise ValueError("IEGR returned no candidates.")
scored = dt.score_from_components(
    variants, model="DecoderTCR-ESMC_300M", device="cpu"
)
scored.to_csv("cdr3b_candidate_scores.csv", index=False)
print(scored[["name", "cdr3b", "ok", "tcr_reason", "hla_reason",
              "pll_DecoderTCR-ESMC_300M"]])

What this result establishes

The table contains receptor candidates and model scores in the chosen target context. It does not establish receptor expression, binding, specificity or T-cell activation. Changing only one region makes the design scope explicit and simplifies comparison with the starting template.

To redesign alpha CDR3, use region="cdr3a" and insert the returned sequence into cdr3a. Joint CDR3 generation needs careful mapping back to both chains; this introductory notebook uses a single region.
