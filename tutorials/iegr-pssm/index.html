Summarize an IEGR candidate set

IEGR generates peptide candidates in a TCR–HLA context. A position-specific scoring matrix (PSSM) can summarize which amino acids occur at each position in that generated set, relative to a stated background distribution.

This differs from the masked peptide profile, which reads probabilities directly from the model. Here the matrix is a descriptive calculation over the returned candidate sequences.

Generate peptides with IEGR

Python · adapted from the public API
import DecoderTCR as dt
import pandas as pd
from tutorial_helpers import candidate_pssm

clone = {
    "trav": "TRAV21", "traj": "TRAJ6", "cdr3a": "CAVRPGGAGPFFVVF",
    "trbv": "TRBV7-9", "trbj": "TRBJ2-7", "cdr3b": "CASSLGQAYEQYF",
    "hla": "HLA-B*27:05",
}
# Teaching settings: inspect and change for your analysis.
designs = dt.design_peptides(
    clone, length=9, n=10, method="iegr", temperature=0.1,
    seed=42, gibbs_rounds=10, gibbs_subset_size=5,
    rescore=True, from_genes=True,
    model="DecoderTCR-ESMC_300M", device="cpu",
)
designs.to_csv("iegr_candidates.csv", index=False)
print(f"Returned {len(designs)} unique candidates.")

Peptide-design API: IEGR, rescoring and return columns. The requested count is an upper bound: refinement can return fewer unique sequences. The saved candidates include PLL from the separate rescoring step; the PSSM counts each candidate equally, without weighting by PLL.

Calculate counts, frequencies and log odds

The helper counts each unique returned sequence once. It adds a total pseudocount mass of one per position, distributed uniformly across amino acids, then calculates log-base-two odds against that uniform background. These are explicit teaching conventions, not DecoderTCR defaults or published benchmark values.

Definition · applied separately to each position and amino acid
frequency = (count + pseudocount_mass * background) / (number_of_sequences + pseudocount_mass)
PSSM = log2(frequency / background)
Python · adapted from the public API
counts, frequencies, pssm = candidate_pssm(
    designs["sequence"].tolist(), pseudocount_mass=1.0
)
for name, rows in [("counts", counts), ("frequencies", frequencies), ("pssm", pssm)]:
    pd.DataFrame(rows).to_csv(f"iegr_{name}.csv", index=False)
print(pd.DataFrame(pssm))

Interpret the matrix

Positive entries indicate enrichment relative to the chosen background; negative entries indicate depletion. The pseudocount prevents infinite log odds for absent letters. A small or highly similar candidate set gives a narrow summary, and IEGR refinement states are not independent samples of the full model distribution.

Keep the candidate count, background, pseudocount, seed and generation settings with the matrix. It describes model-generated candidates, not experimentally measured binding preferences. Summing its entries does not reproduce DecoderTCR PLL.
