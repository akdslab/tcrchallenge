Try DecoderTCR in your browser

Score a small set of TCR–peptide–HLA hypotheses in the Hugging Face sandbox. No local installation is needed.

Run the prefilled example

  1. Open the DecoderTCR sandbox. If the Space asks you to sign in, log in to Hugging Face or create an account.
  2. Start with the example already filled into the form. Click Run binding prediction and wait for the status message to finish.
  3. Read the Prediction result table, then select Download complete results to save the CSV.

The sandbox uses DecoderTCR-ESMC 600M (release 1.5). Workbench defaults to 300M; use the same model when comparing results.

Enter your own receptor and target

Replace the eight input fields below. The optional Pair name is a label for your result. Use amino-acid sequences for the CDR3s and peptide, and gene or allele names for the other fields. Include the CDR3’s conserved starting C and terminal F/W anchors.

The prefilled example is for learning the interface; its score does not establish binding.

The sandbox reconstructs receptor chains from the supplied gene calls and looks up the HLA sequence. It supports human HLA class I (A, B and C) with peptides of 8–11 amino acids. See the glossary for the input terminology.

Use the scores to rank hypotheses

  • PLL is the average peptide log-likelihood. Higher values mean the peptide fits the receptor–HLA sequence context better under the model.
  • z is a context-conditional standardized score for comparing peptide fit across contexts.
  • entropy describes model uncertainty across peptide positions. Very low entropy can make a z-score unstable.

Use these scores to rank candidates for testing. They do not give a probability of binding or confirm binding experimentally. Save the complete CSV with your results.

Rows that cannot be reconstructed remain unscored in a partial batch result. Read reconstruction_reason in the downloaded CSV, correct the relevant gene, HLA or peptide input, and try again. An empty score is not evidence of non-binding.

Upload up to 200 pairs

Expand Score the same inputs from a CSV. Start with the example pairs CSV, then replace or add rows while keeping these column names:

name,trav,traj,cdr3a,trbv,trbj,cdr3b,hla,peptide

Each row is one receptor–HLA–peptide hypothesis. Upload your CSV and click Run batch prediction. Keep the file to 200 pairs or fewer. Download the complete results and inspect unscored rows before interpreting the ranking.

Screen a small 10x repertoire

  1. Expand Score a 10x repertoire against a peptide panel.
  2. Upload a Cell Ranger filtered_contig_annotations.csv file and a peptide-panel CSV with hla and peptide columns. To learn the format, use the example contig file and example peptide panel.
  3. Set Minimum clone size (cells) and Max receptors to keep the job small. Supply a donor ID if your contig file has no donor_id column.
  4. Click Run repertoire prediction and download the results.

Complete alpha/beta receptors are paired with every target in the panel. Receptors × panel rows must be 200 or fewer. For example, 50 receptors and 4 targets make 200 hypotheses. Lower Max receptors, raise Minimum clone size, or shorten the panel if the job exceeds the limit. The largest clones are kept first.

Limits and troubleshooting

If the Space is starting or busy, wait for it to become ready before submitting. For input errors, check the displayed message and reconstruction details; if no rows can be reconstructed, correct the inputs before resubmitting. A class II HLA or a peptide outside the 8–11 amino-acid range is outside this sandbox’s supported input scope.

For larger runs or more control over model settings, use the local TCR-Workbench setup guide. For code and checkpoint access, see code and model downloads. To report a confusing result or error, use Feedback.
