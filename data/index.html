Download model weights

A checkpoint is a file containing the trained model’s parameters, also called weights.

DecoderTCR

After following the setup guide, run this command from the DecoderTCR folder to download the default sequence-model checkpoint.

Shell
uv run python scripts/download_weights.py -m DecoderTCR-ESMC_600M
Select a checkpoint with -m

Without -m, the downloader selects every registered checkpoint. Select the model that matches your hardware and keep that same name in the scoring call.

Report and cite your results

When sharing a result, include the source revision, checkpoint, input data version, device, and inference settings. Preserve failed inputs alongside the results. Cite the model and the original datasets you use.
