Model sizes and downloads

Use these identifiers to select a model. TCR-Workbench defaults to 300M; the browser sandbox uses 600M. See the size and hardware guide before preparing a larger model.

Current DecoderTCR models
SizeModel identifierTCR-Workbench selection
300Mdecodertcr@1.5.0:300M--model esmc-300m
600Mdecodertcr@1.5.0:600M--model esmc-600m
6Bdecodertcr@1.5.0:6B--model esmc-6b

The standalone DecoderTCR package requires Python 3.12. Its public weights require no Hugging Face account. For direct downloads and model loading, follow the checkpoint guide and weight-download script. Keep the code and checkpoint release matched, and review the supplied license.

Check memory before using a larger model

After installing Workbench, check a model’s memory requirements before downloading it:

Terminal · plan a 600M run
python3 tcr.py prepare-model --model esmc-600m --plan

For 6B, replace esmc-600m with esmc-6b. This check does not download weights.

For TCR-Workbench, complete the local setup. To change the saved default, add --model esmc-600m or --model esmc-6b to the full setup command for your computer. To choose a model for a single analysis, include the option on that command:

Terminal · 600M example
python3 tcr.py pmhc-profile --model esmc-600m \
  --hla 'HLA-A*02:01' --length 9 --out results/profile-600m

For 6B, replace esmc-600m with esmc-6b and use a new output folder. Check the hardware guidance first. Weights download automatically when needed.
