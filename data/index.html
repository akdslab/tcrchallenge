Download current model weights

A checkpoint contains a trained model’s parameters, also called weights. The current model identifiers are decodertcr@1.5.0:300M, decodertcr@1.5.0:600M and decodertcr@1.5.0:6B.

For direct model use, follow the checkpoint guide and the repository’s weight-download script. Keep the code and checkpoint release matched, and review the license supplied with the model you use.

TCR-Workbench defaults to 300M; its aliases esmc-300m, esmc-600m and esmc-6b select the corresponding current checkpoints. For local use, follow the package setup instructions. Weights are downloaded and cached when needed; Apple setup can prepare them before the first analysis. The browser sandbox uses 600M, so its scores can differ from the local default.

Report and cite your results

When sharing a result, include the source revision, full model identifier, input data version, device and inference settings. Preserve failed inputs alongside the results. Cite the model and the original datasets you use.
