Shared biological inputs

Both models use the same types of input to describe a complex: the paired TCR alpha and beta chains, an HLA molecule, and a peptide. DecoderTCR provides sequence scores; DecoderTCR-Fold is a folding model for TCR–pMHC structure prediction and interaction scoring.

The sequence tutorials use HLA class I examples and cover partial contexts, such as a peptide with HLA alone. Before preparing your own inputs, check each model’s documentation for HLA class and allele coverage, file formats, and input preparation.

How the sequence model works

DecoderTCR is a protein language model fine-tuned from ESM-C base. It scores a peptide sequence in the context of a T-cell receptor and an HLA molecule.

The current release is DecoderTCR 1.5.0 (decodertcr@1.5.0), in 300M, 600M and 6B sizes. It uses the V2 sequence convention, an update from the earlier V0.3 models. Scores and benchmarks from the two releases are not interchangeable.

You can supply V and J genes and the CDR3 sequence for each receptor chain, an HLA allele, and a peptide. The software reconstructs the receptor chains and looks up the HLA reference sequences before scoring.

Supported tasks

  • Score pairs: score peptide–HLA or TCR–pMHC combinations, including tables prepared from receptor repertoires.
  • Explore a peptide profile: inspect amino-acid preferences at peptide positions for a chosen context, and export them as a position-specific scoring matrix (PSSM).

Check the current hardware and preparation guidance before choosing a larger model. The published website benchmarks describe legacy releases, not a comparison of these current models.

Interpreting the score

The score is not a probability of binding.

DecoderTCR masks the whole peptide and reports the mean log-probability (PLL) it assigns to the candidate residues in the supplied context. A higher score ranks a candidate higher. This is an independent-position compatibility score, not a leave-one-residue-out pseudo-log-likelihood. Compare scores within a consistent model and scoring setup; experimental validation is still needed.

Unrecognized HLA alleles and receptor reconstruction failures can produce missing scores. Keep those rows and inspect the reason columns instead of interpreting missing values as non-binders.
