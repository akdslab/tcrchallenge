What to provide

For a TCR–pMHC prediction, supply the V and J genes and CDR3 sequence for each receptor chain, an HLA allele, and a peptide. The software prepares the receptor and HLA sequences for scoring.

The tutorials use HLA class I examples. You can also explore a peptide with HLA alone; check the chosen workflow for its input format and supported alleles.

What DecoderTCR does

DecoderTCR is fine-tuned from ESMC. Use it to score supplied TCR–pMHC combinations, rank candidates within a consistent analysis, or inspect amino-acid preferences across a peptide.

Choose a model size

DecoderTCR is available in 300M, 600M and 6B sizes. The browser sandbox uses 600M. For local use, TCR-Workbench starts with 300M and lets you select any of the three sizes.

What a score means

A higher score indicates a stronger model preference, not a probability of binding.

Compare results from the same model and analysis setup. Use them to prioritize hypotheses for experimental testing.

If an input cannot be scored, inspect the reported reason. A missing score does not mean the pair is a non-binder.
