Skills your assistant can follow

A skill is a short set of instructions that tells a coding assistant how to carry out a task: the inputs to check, the options to choose and the output to save. The TCR-Workbench repository ships its skills in the code itself, so there is no server to connect to — your assistant reads them from the folder you open.

Two skills are bundled for the sequence model:

  • Setup skill (skills/tcr-workbench-setup/SKILL.md) — installs the command-line tool, picks the right option for your computer and verifies the model is ready.
  • Analysis skill (skills/tcr-workbench/SKILL.md) — guides the assistant through scoring, peptide profiles and repertoire screening.

Choose where the model runs

The sequence model runs locally through the TCR-Workbench CLI; its skills install the tool and run analyses on your computer. Installing a skill does not by itself download model weights — the setup guide and each tutorial explain when weights are fetched.

Use a bundled skill

Open the tcr-workbench folder in your assistant and explicitly ask it to read the repository instructions and skills. Follow the setup commands to install DecoderTCR 1.5.0 from GitHub and download its public weights. No Hugging Face account is needed. For example:

Message to your assistant · install and score
Read AGENTS.md, skills/tcr-workbench-setup/SKILL.md, and
skills/tcr-workbench/SKILL.md in this folder.
Check the installation with python3 tcr.py doctor. If setup is needed,
use the device for my machine and these setup options:
--decoder-source git+https://github.com/akdslab/DecoderTCR.git@077900508a4ab8186a7c3c60f1ca25a4c10b02e8
--weight-source huggingface
Use DecoderTCR 1.5.0 with the default 300M model, then run doctor again.
Then follow https://tcrchallenge.org/tutorials/quickstart/

Use my CSV of paired receptor annotations, peptides and HLA alleles.
Check the inputs, then score a small batch with the 300M checkpoint on CPU.
Save all rows and run settings; explain failed reconstructions and the scores.

Each sequence-model tutorial includes a ready-to-copy message for its task. Add your own research question and input filenames.

Keep a record of the analysis

Ask the assistant to save the input files, outputs and rows that could not be processed, together with the model version, device and settings. It should explain the output using the selected model's documentation: sequence PLL, structure-model pair scores and structure confidence measures have different meanings.

The tutorial catalog covers each workflow. You can also run the sequence-model commands directly, without a coding assistant.
