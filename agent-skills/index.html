Model instructions, ready for your assistant

A skill describes how to carry out a task: the inputs to check, the model to use and the output to save. Biohub provides these instructions through an MCP server. MCP, the Model Context Protocol, lets an assistant retrieve instructions and discover the tools a server makes available.

Connect once, then ask the assistant to read the guidance for your chosen model and research question. Each tutorial includes a message you can copy into the conversation.

First time using a coding assistant?

Start with Set up a coding assistant. It covers the app, sign-in, project folder, Biohub connection and first model run.

Choose where the model runs

The MCP connection provides access to instructions and available tools. Each task guide specifies its computing environment, code and weights. Sequence tutorials include local Python examples; structure tutorials use Google Colab. Connecting to MCP does not itself install a model or provide a GPU.

Connect your assistant

The same Biohub server supplies guidance for both models. Choose your assistant below, or follow the step-by-step connection guide.

Codex

Add Biohub in Settings → MCP servers in the desktop app, or use the Codex CLI. Use /mcp to check the connection.

Claude Code

Add Biohub to your project’s MCP configuration or use the Claude Code CLI. Use /mcp in the session to check the connection.

Check access to the model instructions

Send this message after connecting. The assistant should retrieve the instructions from Biohub and identify what it read.

Message to your assistant · connection check
Read the model instructions available through Biohub MCP for DecoderTCR and DecoderTCR-Fold.
Show the instruction titles or identifiers and their versions, if provided.
List the available task helpers and explain which model fits each task.
Tell me where the model will run and what setup it needs. Do not run an analysis yet.

If it cannot retrieve the instructions, return to the connection checks. You can still read and run the notebooks directly.

Describe your analysis

Give the assistant your question, input filenames and computing environment. For example:

Task helper: score_tcr_pmhc · DecoderTCR

Read the helper’s instructions through Biohub MCP, then run it in the environment specified by the guide. You can also follow the notebook step by step.

Message to your assistant
Use Biohub MCP to read the DecoderTCR instructions and the score_tcr_pmhc task guide.
Use the helper interface described there.
Follow https://tcrchallenge.org/tutorials/quickstart/

Use my CSV of paired receptor annotations, peptides and HLA alleles.
Check the inputs, then score a small batch with the 300M checkpoint on CPU.
Save all rows and run settings; explain failed reconstructions and the scores.

For DecoderTCR-Fold, choose structure prediction or pair scoring and use that guide’s assistant message.

Keep a record of the analysis

Ask the assistant to save the input files, outputs and rows that could not be processed, together with the model version, device and task settings. It should explain the output using the selected model’s documentation: sequence PLL, structure-model pair scores and structure confidence measures have different meanings.

The tutorial catalog covers each workflow. Its notebooks remain available for researchers who prefer to run the steps themselves.
